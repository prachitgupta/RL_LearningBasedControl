\section{Question 3}
\subsection*{(a)}
\addcontentsline{toc}{subsection}{(a)}

$\widehat S$ is finite subset of its 'convex' hull $S$
\[
\Rightarrow\text{ given }\sum_{i=1}^M\lambda_i s_i=x
\quad\text{where }\sum\lambda_i=1
\]
\[
\widetilde J_k(x)=\widetilde J_k\left(\sum_{i=1}^M\lambda_i s_i\right)
\]

using convexity (Jensen's inequality)
\[
\widehat J_k(x)=\widehat J_k\left(\sum_{i=1}^M\lambda_i s_i\right)
\le\sum_{i=1}^M\lambda_i\widehat J_k(s_i)
\]
$\therefore$ this is true for every feasible $\lambda$
that includes minimizing one
\[
\Rightarrow\widehat J_k(x)\le
\min\left\{\sum_{i=1}^M\lambda_i\widehat J_k(s_i)
\mid\lambda_i\in\text{feasible set}\right\}
\]
\[
\Rightarrow\boxed{\widehat J_k(x)\le\widetilde J_k(x)}
\]

\subsection*{(d)}
\addcontentsline{toc}{subsection}{(d)}
Proof by induction like we did in lecture 5

Base case $k=N$ ($\because$ we go backwards)

given
\[
J_N(x)=\widetilde J_N(x)=\widehat J_N(x)
\]
which is same as
\[
\Rightarrow J_N(x)\le\widetilde J_N(x)\le\widehat J_N(x)\quad\text{so true }\checkmark
\]

let's assume its true for $k+1$
\[
\Rightarrow J_{k+1}(x)\le\widehat J_{k+1}(x)\le\widetilde J_{k+1}(x)\tag{2}
\]

Using definition
\begin{align*}
J_k(x_k)&=\E\left[g_k(x_k,\vec u_k,w_k)
+J_{k+1}\left(f_k(x_k,\vec u_k,w_k)\right)\right]\\
&\le\E\left[g_k(x_k,\vec u_k,w_k)
+\widetilde J_{k+1}\left(f_k(x_k,\vec u_k,w_k)\right)\right]
\quad\text{(using (2))}\\
&\le\min_{u_k\in U_k}\E\left[g_k(x_k,u_k,w_k)
+\widetilde J_{k+1}\left(f_k(x_k,u_k,w_k)\right)\right]\\
&\le\widehat J_k(x_k)\qquad\text{(using definition of }\widehat J\text{)}
\end{align*}

also using Convexity
\[
\widehat J_k(x_k)\le\widetilde J_k(x_k)
\]

so by induction

$\because$ Base case is trivially True

\& $k$th case is true iff $k+1$th case is True

We can say that
\[
\boxed{J_k(x)\le\widehat J_k(x)\le\widetilde J_k(x)}
\quad\forall x\in S\ \&\ \forall k\in\{0,1,2,\ldots,N\}
\]
